# TheOdcMfUI – Microfrontend Setup Guide

Welcome to the **TheOdcMfUI** Microfrontend. This guide will help you integrate and configure the shared UI components built using **Vite**, **React**, **MUI**, and [`@originjs/vite-plugin-federation`](https://github.com/originjs/vite-plugin-federation).

## 🔍 Overview

**TheOdcMfUI** is a **Vite-powered Microfrontend** that exposes reusable UI modules such as layouts, forms, theme providers, etc. It is intended to be consumed by remote apps via **Module Federation**.

---

## 📦 Features

- Built using **Vite + React 19 + MUI v7**
- Exposes shared UI components
- Optimized for **Module Federation**
- Singleton shared dependencies (React, MUI, etc.)
- Easy local development with full HMR support

## 🧩 Integration in Remote App

To consume `TheOdcMfUI` from a host or remote app:

---

### ✅ Step 1: Install Dependencies

```bash
npm install @originjs/vite-plugin-federation --save-dev
```

---

### ✅ Step 2: Update vite.config.js

```js
import { defineConfig, loadEnv } from "vite";
import react from "@vitejs/plugin-react";
import federation from "@originjs/vite-plugin-federation";

export default defineConfig(({ mode }) => {
  const env = loadEnv(mode, process.cwd(), "");

  return {
    base: "/",
    plugins: [
      react(),
      federation({
        name: "TheOdcUserFE",
        remotes: {
          TheOdcMfUI: `${env.VITE_MF_REMOTE_URL}/assets/remoteEntry.js`,
        },
        shared: {
          react: {
            singleton: true,
            strictVersion: true,
            requiredVersion: "^19.0.0",
          },
          "react-dom": {
            singleton: true,
            strictVersion: true,
            requiredVersion: "^19.0.0",
          },
          "@mui/material": {
            singleton: true,
            strictVersion: true,
            requiredVersion: "^7.0.0",
          },
          "@emotion/react": {
            singleton: true,
            strictVersion: true,
            requiredVersion: "^11.14.0",
          },
          "@emotion/styled": {
            singleton: true,
            strictVersion: true,
            requiredVersion: "^11.14.0",
          },
          "react-router-dom": {
            singleton: true,
            strictVersion: true,
          },
          "prop-types": {
            singleton: true,
            strictVersion: true,
          },
          "react-hook-form": {
            singleton: true,
            strictVersion: true,
            requiredVersion: "^7.56.0",
          },
          "@hookform/resolvers": {
            singleton: true,
            strictVersion: true,
          },
          zod: {
            singleton: true,
            strictVersion: true,
          },
        },
      }),
    ],

    server: {
      hmr: true,
      cors: true,
      proxy: {
        "/remoteEntry.js": env.VITE_MF_REMOTE_URL,
      },
    },

    build: {
      modulePreload: false,
      target: "esnext",
      minify: false,
      cssCodeSplit: false,
    },
  };
});
```

---

### ✅ Step 3: Add Environment Variable

In your `.env` file:

```env
# Remote URL
VITE_MF_REMOTE_URL=https://theodc-mf-ui.vercel.app

# Local URL
VITE_MF_REMOTE_URL=http://localhost:5000
```

### 🧩 Example Usage

Use components from `TheOdcMfUI` like this:

```js
const Header = await import("TheOdcMfUI/Header");

// Or with React.lazy
const Header = React.lazy(() => import("TheOdcMfUI/Header"));
```

Use inside a Suspense boundary:

```jsx
<Suspense fallback={<div>Loading...</div>}>
  <Header />
</Suspense>
```
