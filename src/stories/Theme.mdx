# 🎨 The ODC Design System & Tokens

A comprehensive design system built with custom Material UI (MUI v7) tokens, semantic palettes, responsive typography, and dual light/dark modes tailored for **The ODC / The ODC**.

## 📦 Usage & Integration

### 1. Theme Provider Wrapper

Wrap your root application in `ThemeProviderWrapper`:

```jsx
import { ThemeProviderWrapper } from "TheOdcMfUI/theme";

export default function App() {
  return (
    <ThemeProviderWrapper>
      <YourAppRoutes />
    </ThemeProviderWrapper>
  );
}
```

### 2. Access Theme Context & Switcher

Use `ThemeContext` to reactively read or switch modes:

```jsx
import React, { useContext } from "react";
import { ThemeContext } from "TheOdcMfUI/theme";
import { IconButton } from "@mui/material";
import { DarkMode, LightMode } from "@mui/icons-material";

export const ThemeSwitch = () => {
  const { mode, toggleTheme } = useContext(ThemeContext);

  return (
    <IconButton onClick={toggleTheme} color="inherit">
      {mode === "dark" ? <LightMode /> : <DarkMode />}
    </IconButton>
  );
};
```
